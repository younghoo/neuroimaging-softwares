## [FSL](https://fsl.fmrib.ox.ac.uk/fsl/docs/)

FSL is a comprehensive software package for multi-modal MRI analysis, but I primarily use it for DWI data. It is well-documented and is my favorite package.

Some useful links:
* [documentation](https://fsl.fmrib.ox.ac.uk/fsl/docs/)
* [course](https://open.oxcin.ox.ac.uk/pages/fslcourse/website/index.html)
* [mailing list](https://www.jiscmail.ac.uk/cgi-bin/webadmin?A0=fsl)
