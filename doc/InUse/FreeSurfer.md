## [FreeSurfer](https://surfer.nmr.mgh.harvard.edu/)

FreeSurfer is comprehensive software package for multi-modal MRI analysis, but I only use it for T1-weighted structural data.

Some useful links:
* [wiki](https://surfer.nmr.mgh.harvard.edu/fswiki)
* [source code](https://github.com/freesurfer/freesurfer)
* [mailing list](https://www.mail-archive.com/freesurfer@nmr.mgh.harvard.edu/)
