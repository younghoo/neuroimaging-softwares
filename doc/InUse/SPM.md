## [SPM](https://www.fil.ion.ucl.ac.uk/spm/)

SPM is a comprehensive software package for T1 and fMRI analysis. I usually use it for task fMRI modeling. One limitation of SPM is its reliance on MATLAB, which can make it difficult to integrate with other software packages.

Some useful links:
* [manual](https://www.fil.ion.ucl.ac.uk/spm/doc/manual.pdf)
* [mailing list](https://www.jiscmail.ac.uk/cgi-bin/webadmin?A0=spm)
