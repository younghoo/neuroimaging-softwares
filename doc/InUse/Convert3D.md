## [Convert3D](http://www.itksnap.org/pmwiki/pmwiki.php?n=Downloads.C3D)

Convert3D is used to convert registration matrices from ANTs format to FSL format (and vice versa).

Some useful links:
* [download](https://sourceforge.net/projects/c3d/files/c3d/)
* [documentation](https://sourceforge.net/p/c3d/git/ci/master/tree/doc/c3d.md)
